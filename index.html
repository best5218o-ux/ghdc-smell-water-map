시연판 안내 · 지도의 「시연」 표시 신고·조치는 기능 설명용 가상 데이터이며 실제 민원이 아닙니다. 시설 위치도 대략적인 시연용 좌표입니다. 이 화면에서 직접 입력한 신고는 이 기기에만 저장되며 공사에 전달되지 않습니다. 실제 운영 시에는 공사 서버·누리집에 연결합니다.

● 색: 강도(0~5) · ◆ 공사 시설 · 위치는 약 500m 격자 중심으로만 표시합니다. 지도를 눌러 위치를 선택한 뒤 「신고」 탭에서 접수하세요.

⚠ 냄새 진원지에 접근하지 마세요. 호흡 곤란·두통이 있으면 즉시 이동하고, 위급하면 119.

냄새 가능 시간대 (시범 지표)

공개 기상 예보(Open-Meteo, 키 불필요)의 풍향·풍속·습도와 최근 신고를 합쳐 향후 12시간의 점검 우선도를 계산합니다. 현재는 규칙 기반 지표이며 학습 모형이 아닙니다. 신고가 시간대별로 충분히 쌓이면 랜덤포레스트 계열로 대체하고 시간 순서 분할로 검증합니다(제안서 ④단계).

참고 근거

Smell Pittsburgh: 신고 26,556건 기반, 향후 8시간 냄새 예측 F-score 0.70 (Hsu 외, arXiv:1912.11936). 시카고 물재생구역: H2S·기상·운영 자료 결합으로 악취 민원 3일 전 예측 정확도 60% 이상(Mulrow 외, 2020). 위 두 결과는 해외 사례이며 김해에서의 성능은 시범으로 검증합니다.

이 시범판의 한계

  • 데이터 저장: 현재 시연판은 기기 내 저장입니다. 실제 시범에서는 공사가 지정한 서버(또는 무료 웹 도구)로 신고를 모읍니다.
  • 예측은 규칙 기반 지표이며 효과는 시범 첫 달 측정 후 확정합니다.
  • 시설 좌표·주거지 방위는 시연용 가정치입니다.
  • 개인정보: 이름·연락처를 받지 않고 위치는 격자 단위만 보관합니다.
