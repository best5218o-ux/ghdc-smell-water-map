# 냄새·물 신뢰 지도 (시범판)

김해시도시개발공사 「2026 AI·ESG 혁신경영 아이디어 공모」 제안 「냄새·물 신뢰 지도」의 작동 시범판(웹·앱 PWA).

- 신고(QR, 로그인·설치 없음) → 공사 조치 기록 → 일 단위 공개 → 12시간 점검 우선도
- 지도에 표시된 신고·조치는 **시연용 가상 데이터**입니다. 시설 좌표도 시연용입니다.
- 입력한 신고는 해당 기기(localStorage)에만 저장됩니다. 실제 시범 때는 공사 서버·누리집에 연결합니다.
- 점검 우선도는 규칙 기반 지표이며 학습 모형이 아닙니다. 기상은 Open-Meteo 공개 예보를 씁니다.
- 휴대폰 브라우저 「홈 화면에 추가」로 앱처럼 설치됩니다.

실행: 정적 파일이므로 `index.html`을 열거나 GitHub Pages로 서비스합니다.
